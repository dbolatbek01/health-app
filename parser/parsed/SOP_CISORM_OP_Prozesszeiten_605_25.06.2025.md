### **1. Herz-, Thorax- und Gefäßchirurgie**

#### **1.1 Erste Position**

Die ersten Patienten werden durch die Station zu dem im OP-Terminplan definierten Zeitpunkt an der OP-Schleuse bereitgestellt (s. [SOP630](https://intranet.dhzb.de/fileadmin/user_upload/Dokumente/SOP/OP-Management/SOP630.pdf) CISORM: OP-Abruf und Transporte von Stationen). 

Die Zielzeiten für die weiteren Prozessschritte sind wie folgt: 

| Uhrzeit | Maßnahme                                      |
|---------|-----------------------------------------------|
| 06:45   | Anästhesieüberwachungsbeginn durch den AN-FD  |
| 07:15   | Narkosebeginn                                 |
| 07:45   | Chirurgischer Assistent anwesend zur Lagerung |
| 07:45   | Freigabe Anästhesie                           |
| 07:45   | Ende Vorbereitung OP-FD                       |
| 07:50   | Saaleinfahrt                                  |
| 08:00   | Operateur anwesend                            |
| 08:15   | Schnitt                                       |

Wartezeiten werden durch alle Berufsgruppen in Torin dokumentiert. 

#### **1.2 Wechselzeit**

Die Folgepatienten werden durch die Anästhesie in Absprache mit der OP-Koordination bestellt (s. [SOP630](https://intranet.dhzb.de/fileadmin/user_upload/Dokumente/SOP/OP-Management/SOP630.pdf) CISORM: Abruf von Patienten / Transport in den OP). 

Die Zielzeiten für die Prozesszeiten beim Patientenwechsel sind wie folgt: 

| Minuten | Maßnahme                                                 |
|---------|----------------------------------------------------------|
| 30      | Saalausfahrt bis Saaleinfahrt                            |
| 40      | Wechselzeit der Anästhesie (ECM – Freigabe Folgepatient) |
| 40      | Wechselzeit des OP-FD (ECM – Ende Vorbereitung OP-FD)    |
| 75      | Naht-Schnitt-Zeit  HTG                                   |

Wartezeiten werden durch alle Berufsgruppen in Torin dokumentiert.

# **4. Definition der Zeitpunkte**

| Zeitpunkt                        | Maßnahme                                                                                                                                                        |
|----------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Abruf von Station                | 1. Position: Zeitpunkt laut OP-Terminplan                                                                                                                       |
|                                  | Folgende Positionen: Anruf auf Station                                                                                                                          |
| Anästhesie-Pflege / Arzt         | 1. Patienten-Kontakt AN-FD oder AN-AD (Anästhesie-Arztdienst)  =                                                                                                |
| Präsenz                          | "Überwachungsbeginn"                                                                                                                                            |
|                                  | Injektion erstes Narkosemedikament                                                                                                                              |
| Beginn Anästhesie                | oder                                                                                                                                                            |
|                                  | 1. Punktion (AK / ZVK) bei wachen Patienten                                                                                                                     |
| Freigabe Anästhesie              | Freigabe für Lagerung / Clipping Haare                                                                                                                          |
| Ende Einleitung                  | Ende aller Maßnahmen der Anästhesie-Einleitung                                                                                                                  |
| Patient im OP-Saal               | Auffahren Tisch auf OP-Säule                                                                                                                                    |
| Beginn chirurgische<br>Maßnahmen | Beginn der Maßnahmen durch einen Arzt der eingriffsdurchführenden Abteilung im<br>OP-Saal (bspw. ärztliche Lagerung, US-Untersuchung, Abwaschen, Abdecken etc.) |
| Schnitt                          | Bei Interventionen: 1. Perkutane Punktion                                                                                                                       |
| Naht                             | Bei Interventionen: Ende der interventionellen/operativen Manipulation                                                                                          |
| Ende chirurgische<br>Maßnahmen   | Ende Verband / Entlagerung der behandelten Person                                                                                                               |
| Patient aus dem Saal             | Patient verlässt OP-Saal                                                                                                                                        |
|                                  | Extubation; bei LA = Ende chirurgische Maßnahmen                                                                                                                |
| Ende Anästhesie                  | Beatmet verlegte Patienten = Überwachungsende                                                                                                                   |
| Ende Anästhesie-Pflege /         | Übergabe ITS / PACU / Aufwachraum oder an den Pflegedienst der Station                                                                                          |
| Arzt-Präsenz                     | respektive Ende Personalbindung am Patienten (AN FD)                                                                                                            |
